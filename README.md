# 專案治理 Governance

## 核心團隊

Clear Space Lab 淨地實驗室由三位核心創始成員組成，負責專案方向、版本發布、雲端營運與社群管理。

## 核心成員自律承諾

作為一個反偷拍、保護隱私的公益專案，核心成員的言行會被放大檢視，也應該被放大檢視。

三位核心創始成員共同承諾：

> 若任何一位核心成員有涉及**性騷擾、暴力、歧視**等不當言行，該成員將**主動離開團隊**，以表達對本專案與使用者的負責。

此承諾高於任何個人貢獻。專案的信任，比任何一位成員都重要。

核心成員同樣受 [社群行為準則](CODE_OF_CONDUCT.md) 約束，且不享有任何豁免。

## 決策方式

- **日常開發**：透過 GitHub PR 審查，至少一位維護者核准後合併。
- **重大決策**（資料政策、雲端選擇、合作夥伴、授權變更）：公開於 GitHub Discussions 討論，由核心團隊共識決定。
- **資料與隱私政策的任何變更**必須公開公告，不得靜默修改。

## 長期移交

淨地的長期目標是**完整移交給具公信力的公益團體營運**：

- 公益團體承擔營運成本（雲端、認證等）
- Clear Space Lab 持續提供技術維護
- 程式碼維持 MIT 授權開源，不因移交而改變

## 維護者

成為維護者的方式：持續貢獻高品質 PR、參與 Review 與讀書會，由核心團隊邀請。
